# BazarHQ

A multi-merchant e-commerce SaaS platform for Bangladesh.

## Approved Technology Stack

- Web: Next.js App Router, React, TypeScript
- Android: React, TypeScript, Capacitor
- Backend: Supabase
- Database: PostgreSQL
- Authentication: Supabase Auth
- Security: PostgreSQL Row-Level Security (RLS)
- Storage: Supabase Storage
- Server-side operations: Supabase Edge Functions

## Version 2.1 Scope

- Customer
- Merchant
- Super Admin
- One store per Merchant
- Merchant-specific subdomain storefronts
- Store-specific cart, checkout, and orders

Delivery Agent functionality and a central
marketplace product catalogue are out of scope
for Version 2.1.

## Project Status

Repository scaffold created.
Application implementation has not started.
